# 馬路求生記 road-survival

台灣街頭版的推箱子＋回合制閃車益智遊戲。你是行人、推嬰兒車的家長或機車騎士，要在違停、騎樓雜物、禁行機車道、兩段式左轉和繞遠路的機車專用道之間，找出一條平安到達目的地的路。

設計決策、尚未定案的事和下一步，請看 [`docs/HANDOFF.md`](docs/HANDOFF.md)。

## 怎麼玩

用瀏覽器打開 `game/index.html` 就能玩，不需要安裝任何東西。

- 方向鍵或 WASD 移動，空白鍵原地等一步，Z 復原，R 重來；手機可以滑動或按畫面上的按鈕。
- 你走一步，所有車子也動一步。
- 紅、橘、黃框是一、二、三步後車子會開到的格子（假設你原地不動）。
- 招牌、盆栽、垃圾桶、三角錐和嬰兒車推得動，一次推一個；違停機車和汽車推不動。

## 關卡

| 關卡 | 角色 | 主題 | 最少步數 |
|---|---|---|---|
| 1 騎樓障礙賽 | 行人 | 騎樓被機車和店家雜物佔滿 | 27 |
| 2 斑馬線上的違停 | 行人 | 違停車擋住行人穿越道 | 17 |
| 3 推嬰兒車回家 | 家長 | 騎樓高低不平，嬰兒車過不了台階 | 30 |
| 4 二段式左轉 | 機車 | 禁行機車道與兩段式左轉 | 29 |
| 5 機車專用道過橋 | 機車 | 主橋禁行機車，只能繞專用道 | 25 |
| 6 騎樓障礙賽・原版 | 行人 | 地獄模式 | 49 |

最少步數由 `game/build.js` 在建置時用解題程式算出來，三星門檻是最少步數加 2。

## 資料夾

```
game/
  core.js        遊戲規則（純邏輯，瀏覽器和 Node 共用）：移動、推動、車流、紅綠燈、罰單、危險預告、解題程式
  levels.js      關卡資料（地圖字元說明寫在檔案開頭）
  template.html  畫面與操作（2D 版）
  build.js       解出每一關的最少步數，把以上三個檔案合成 index.html
  index.html     建置好的遊戲，直接打開就能玩（不要手動改它）
  tools/         檢查工具：危險預告是否準確、模擬玩家通過率、在瀏覽器裡把每關的最短解跑一遍
art/
  concepts/      五個美術方向的概念圖與提案頁（index.html）
  concept.html   產生概念圖的 3D 場景（three.js），網址加 ?s=candy|neon|clay|comic|dawn 切換風格
  keyart.html    會動的 3D 視覺樣張
  export-scene.js / build.js / render.js  匯出場景、組出 art/dist/、重新渲染概念圖
  prototypes/    早期的 2D 風格比較
```

## 開發

```bash
npm install
```

改了 `game/` 底下的 `core.js`、`levels.js` 或 `template.html` 之後：

```bash
npm run build
```

確認紅橘黃框跟實際撞車的位置完全一致：

```bash
npm run check
```

用無頭瀏覽器把每一關的最短解玩一遍：

```bash
npm run play-all
```

重新產生 `art/concepts/` 裡的五張概念圖：

```bash
npm run art:render
```

關卡改完一定要跑 `npm run build`：只要有任何一關解不出來，建置就會直接失敗。

## 設計備忘

- 機車和汽車推不動，因為推別人的機車不符合現實；推得動的是店家擺出來的雜物、施工三角錐和自己的嬰兒車。
- 車子比人快（部分車道一回合走兩格），所以不能跟著車流走在馬路上偷懶。
- 車子從地圖邊緣開進來時，會撞到站在邊緣的人。早期版本沒有這條規則，站在邊緣會變成無敵。
- 美術方向尚未定案，目前的建議是以「黏土定格」為主，「夜市霓虹」做夜間關卡或宣傳圖，詳見 `art/concepts/index.html`。
